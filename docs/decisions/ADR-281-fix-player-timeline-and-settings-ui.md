# ADR-281: Исправление таймлайна плеера (Fallback Duration), кликабельности озвучек и UI настроек

## Статус
Принято (v0.9.11 / build 281)

## Контекст и проблемы
1. В модальном окне настроек присутствовали дублирующие кнопки назад и крестик.
2. При P2P-стриминге ExoPlayer возвращал `duration = C.TIME_UNSET`, отображая таймер `-00:00`.
3. Заголовок фильма в верхней панели обрезался.
4. Переключение чипов озвучек/качества требовало связки с `session.switchToStream`.

## Решение
1. Удалены дублирующие кнопки в шторке, оставлен нативный DragHandle.
2. Внедрен расчет общей длительности с фоллбэком на метаданные фильма (`movieDurationMinutes * 60 * 1000L`).
3. Заголовок плеера защищен `Modifier.weight(1f)` и `TextOverflow.Ellipsis`.
4. Селекторы озвучек и качества напрямую вызывают смену потока с сохранением текущего таймкода.
