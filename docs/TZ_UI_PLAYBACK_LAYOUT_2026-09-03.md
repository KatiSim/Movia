# Movia — Техническое задание: исправление логики воспроизведения и верстки экранов

Дата фиксации: 2026-09-03
Статус: ACTIVE / NOT IMPLEMENTED / NOT VERIFIED

## Задача 1. Интерактивность кнопки воспроизведения на главном баннере

Компонент: `CatalogScreen.kt` / `CatalogHeroBanner` (вкладка «Главная»).

### Проблема

При нажатии на центральную кнопку Play (круг с треугольником) внутри карточки «Главный хит» событие клика не обрабатывается: плеер не запускается, видео не открывается.

### Требования

- Добавить обработчик клика на кнопку воспроизведения (`Box` / `IconButton` с иконкой Play).
- Нажатие на кнопку Play должно немедленно перенаправлять пользователя в `PlayerScreen` с передачей идентификатора контента и параметров первого доступного эпизода:
  - для сериалов — 1 сезон, 1 серия;
  - для фильмов — основной поток.
- Нажатие на саму карточку баннера вне кнопки Play должно открывать карточку описания (`DetailsScreen`).
- Обеспечить визуальный отклик на нажатие: Ripple-эффект с янтарным оттенком.

## Задача 2. Корректировка отступов кнопок «Назад» и «В избранное»

Компонент: `DetailsScreen.kt` (верхняя навигационная панель карточки фильма).

### Проблема

Кнопки «Назад» (←) и «В избранное» (♡) расположены вплотную к верхнему краю экрана, залезают на системную строку состояния (`Status Bar`) и перекрываются вырезом фронтальной камеры / Dynamic Island.

### Требования

Обернуть ряд кнопок в контейнер с обязательным учетом системных отступов:

```kotlin
Modifier
    .statusBarsPadding()
    .padding(top = 12.dp, start = 16.dp, end = 16.dp)
```

- Кнопки должны находиться строго ниже области системных иконок (часы, заряд, Dynamic Island), сохраняя гарантированный зазор не менее `12.dp` от нижней границы строки состояния.
- При вертикальном скролле страницы кнопки должны:
  - сохранять `z-index` поверх контента; либо
  - плавно растворяться / переходить в закрепленный `TopAppBar`.

## Задача 3. Восстановление блоков актерского состава и съемочной группы

Компонент: `DetailsScreen.kt` (основное тело страницы под блоком сюжета).

### Проблема

В процессе обновления дизайна исчезли блоки «В главных ролях» (актеры с фотографиями), информация о режиссере, сценаристах и продюсерах. Отображается только сокращенное поле «Создатель».

### Требования: блок «В главных ролях» (Cast)

- Разместить горизонтальный список (`LazyRow`) с шагом `12.dp` между карточками.
- Каждая карточка актера должна содержать:
  - круглое или скругленное фото;
  - `size = 64.dp`;
  - `ContentScale.Crop`;
  - placeholder при отсутствии сети;
  - реальное имя актера полужирным шрифтом;
  - имя персонажа серым цветом (`onSurfaceVariant`).

### Требования: блок съемочной группы (Crew & Details)

Восстановить сетку параметров:

- «Режиссер»;
- «Сценарий»;
- «Продюсеры»;
- «Оператор»;
- «Композитор».

Вывести дополнительную карточку технических данных:

- оригинальное название;
- точная дата премьеры;
- возрастное ограничение (`16+` / `18+`);
- бюджет;
- сборы;
- поля бюджета и сборов отображать только при наличии в модели данных.

Если данные по персонам отсутствуют в модели API, соответствующий блок должен корректно скрываться (`if (cast.isNotEmpty())` / эквивалент), не оставляя пустых отступов.

## Критерии приёмки

- [ ] Клик по центральному кругу Play на главном баннере сразу запускает воспроизведение потока.
- [ ] Верхние круглые кнопки «Назад» и «В избранное» не пересекаются со шторкой, часами и вырезом камеры ни на одном разрешении экрана.
- [ ] Под описанием сюжета отображаются полноценная карусель актеров с фотографиями и блок создателей проекта.

## Правило верификации

Ни один критерий приёмки не считается выполненным только по факту изменения исходного кода. PASS допускается только после сборки и проверки соответствующего поведения на устройстве / эмуляторе с фактическим запуском UI и плеера.
