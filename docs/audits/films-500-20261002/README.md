# Проверка 500 фильмов Movia
Цель — не менее 500 других фильмов, декодирование видео и матрица озвучка × качество через единственный Media3-плеер без управления экраном.
manifest.json содержит выбранные фильмы; наличие строки здесь не подтверждает воспроизведение.
actions.jsonl записывает каждое действие и его результат. Подписанные медиа-URL, токены, заголовки авторизации и личная библиотека не публикуются.
summary.json содержит текущие счётчики; results/ хранит отдельный результат каждого фильма.
Названия студий не считаются независимо подтверждёнными по техническим меткам контейнера.
Неизвестные и недоступные варианты фиксируются отдельно.
