# Movia — нативный HDRezka, блок 50 минут 6 октября 2026

Начало 21:05 UTC. Предельный срок 21:55 UTC.

Цель — собственная архитектура Movia для всех реально доступных озвучек и представлений, без фиксированного лимита 3×3. LazyMedia Deluxe служит поведенческим ориентиром; его код и runtime не добавлены.

## Реализовано

- Новый самостоятельный hdrezka_transport.py: публичная статья → подтверждённый ID → реальный переводчик → точная серия → опубликованные представления и AJAX-ответы → конкретные листья. ProviderContract HDRezka больше не импортирует Zona transport/config.
- HTTP-профиль собственный и публичный; не используется удалённая конфигурация старого приложения или его account headers. Cookie только из ответа конкретного провайдера и только в его собственный POST.
- Сохраняются все опубликованные варианты; регрессия проверяет 600 листьев. Для сетевых запросов переводчиков ограничены рабочие потоки и очередь, при 403 нет каскада запросов.
- Точное S/E проверяется по публичной странице и ID статьи; неактивные сериалные CDN-ветки не считаются доказательством запрошенного эпизода.
- Надписи качества провайдера сохраняются как advertised_quality. Concrete quality появляется только после измерения реальной высоты видео. Неизмеренное остаётся «Не указано».
- HLS: полная длительность возвращается сразу, измерение размеров среднего сегмента выполняется отдельно в ограниченной очереди. Сегмент не может подменить длительность всего эпизода; зашифрованные и byte-range потоки не получают угаданных размеров.
- Android: подтверждённый полный эпизод получает приоритет перед равноценным неизмеренным transport; реальные health/preferences остаются важнее.
- Android: при явном выборе озвучки полноценный источник этой озвучки не вытесняется другой озвучкой только из-за известного качества. Трейлер не получает этот приоритет. При исчерпании источников остаётся честный fallback с названием реально выбранного голоса.

- Живой транспорт: Интерстеллар (2014), mediaId 158 — 110 сырых листьев, 10 опубликованных голосов.
