# Собственный сервер Movia

Статус: самостоятельный серверный код опубликован в ветке `movia-owned-backend-20261001` проекта `KatiSim/Movia`; внешний сервер ещё не размещён. Проверки на телефоне выполнялись с отдельными временными базами, без изменения пользовательского каталога.

Этот каталог содержит самостоятельную копию Python-движка Movia, API и фоновые задания. На сервере не нужны установленные Zona, LazyMedia Deluxe, Android, Termux, Shizuku, aria2 или TorrServer. Код не читает их каталогов и не запускает их приложения. Совместимость с первоначальным Zona-протоколом использует собственный `runtime/zona-client-profile.json` (3,2 КБ), подготовленный один раз из предоставленного файла. Расчёт воспроизводит исходный результат без чтения APK во время работы; старые папки и переменная `ZONA_APK_PATH` не используются. Пользовательская база и секреты не включены в исходники или Docker-образ.

Новинки, сюжеты, постеры и актёры синхронизируются через собственные задания Movia и TMDB. API отдаёт каталог, поиск, карточки, актёров и сохранённые HTTP-варианты. Тяжёлый поиск источников и метаданных выполняется вне HTTP-обработчика. Свежие фильмы получают отдельную очередь; старый каталог обновляется с собственным курсором. Подписанные URL проверяются/обновляются, без подмены серии или фильма. Источники, недоступные у провайдера, остаются недоступными до следующей успешной проверки.

`/api/providers/config` отдаёт собственную конфигурацию доменов из `runtime/providers.json`. Аналогичная резервная копия включена в APK. Приложение больше не обращается за конфигурацией на сервер LazyMedia: допускаются только активные исходные провайдеры, публичные домены и адрес поискового зеркала. Ключи, лицензии, токены и исполняемый код через этот endpoint не передаются.

`runtime/cloud_main.py` запускает один API и один управляющий поток. Каждый проход ограничивает процессы парсера двумя исполнителями, 30 карточками для источников и небольшими пакетами метаданных. Интервал запуска нового прохода — минимум пять минут; долгий проход увеличивает интервал. Это не обещание появления любого релиза сразу после публикации на любом сайте.

Публичные GET-запросы не запускают TMDB-поиск, ремонт метаданных или торренты. `/internal/*`, `/proxy`, файловые пути, очистка кэша и запись закрыты. Ответы имеют ограничение размера, короткий кэш и ETag. Адреса локальных шлюзов, P2P и заголовки авторизации не публикуются. Медиа поступает непосредственно от провайдера в единственный плеер Movia; сервер не пересылает фильмы через бесплатный хостинг.

## Хранение

Рабочая SQLite-база лежит в `MOVIA_DATA_DIR`. Для сервиса с временным диском предусмотрен приватный PostgreSQL-checkpoint: `MOVIA_SNAPSHOT_DSN`. Каталог экспортируется согласованным чтением в gzip-поток и хранится небольшими блоками в одной транзакции. При восстановлении проверяются SHA-256, формат, полнота и целостность SQLite. ID карточек сохраняются. FTS и индексы восстанавливает собственная миграция Movia. После перезапуска рабочая база восстанавливается до открытия API.

PostgreSQL требует TLS с проверкой сертификата/имени. Для CA хостинга задайте `PGSSLROOTCERT` с путём к смонтированному сертификату. DSN, ключ TMDB, база, сертификаты и `.env` не должны попадать в Git, Docker build context или публичные логи. При использовании постоянного диска вместо PostgreSQL нужен отдельный проверенный механизм резервного копирования.

## Размещение

1. Подключить аккаунт хостинга. Ветка серверного кода уже опубликована обычным Git с телефона: https://github.com/KatiSim/Movia/tree/movia-owned-backend-20261001/backend . Основная ветка и пользовательский индекс сохранены. Аккаунт внешнего хостинга пока не подключён.
2. На Northflank выбрать только **Sandbox**: один бесплатный сервис и одну бесплатную базу. До создания проверить реальные лимиты RAM, диска, сетевого трафика и условия аккаунта. Не выбирать Pay-as-you-go, платный volume или увеличенный план. Бесплатный тариф не является SLA и может меняться.
3. Настроить TLS базы и приватные переменные `MOVIA_SNAPSHOT_DSN`, `PGSSLROOTCERT`, `TMDB_API_KEY` или `TMDB_ACCESS_TOKEN`. Публичный сервис принимает HTTPS через прокси хостинга; порт контейнера `8080`.
4. Перенести согласованный снимок текущего каталога с телефона в checkpoint. Не создавать пустую замену: сервер намеренно отказывается запускаться без начальных данных. Скрипт `python runtime/snapshot_store.py` создаёт checkpoint из `MOVIA_DATA_DIR/catalog.db`.
5. Собрать образ с контекстом `backend/`. Проверить `/health`, все маршруты каталога, сохранение ID и восстановление после перезапуска. Проверка PostgreSQL и Docker на настоящем хостинге пока не проведена.
6. Собрать приложение с `-PmoviaApiBaseUrl=https://<свой-хост>` и пройти build → install → cold launch → crash log → реальное воспроизведение. Код валидирует HTTPS-origin отдельно от локального P2P-шлюза.
7. Только после успешной проверки внешнего API отключить локальную синхронизацию/каталог. Два тяжёлых обогатителя уже остановлены на телефоне; локальный API временно оставлен для работоспособности текущей установленной версии.

Пример локальной проверки:

```sh
PYTHONPATH=runtime python -m unittest discover -s tests -v
docker build -t movia-backend .
docker run --rm --env-file .env -p 8080:8080 movia-backend
```

Параметр Android API меняет источник каталога и обычного резолвера. Локальный P2P-шлюз — отдельная необязательная возможность, пока использующая Termux; HTTP-воспроизведение от встроенных провайдеров её не требует. Для полного отказа от Termux следует использовать серверный HTTP-каталог либо отдельно перенести P2P-движок внутрь Movia.

## Проверенные ограничения бесплатных вариантов, 01.10.2026

- Northflank публикует Sandbox с двумя сервисами, одной базой и двумя cron-задачами без засыпания: https://northflank.com/pricing . Точные доступные аккаунту ресурсы нужно проверить перед размещением. По умолчанию временный диск сервиса — 1 GB и теряется при рестарте: https://northflank.com/docs/v1/application/scale/increase-storage . Поэтому база не должна оставаться только на нём.
- Render Free засыпает после 15 минут простоя, запуск может занимать около минуты: https://render.com/docs/free . Это плохо подходит для цели в пять секунд.
- GitHub Actions подходят для пакетного обновления, но расписание может задерживаться: https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule . Это не постоянно доступный API.
- Cloudflare Workers/D1 подходят для компактного API, но текущий Python/SQLite-парсер не переносится туда без адаптации: https://developers.cloudflare.com/workers/platform/limits/ и https://developers.cloudflare.com/d1/platform/limits/ . Ограничение бесплатной D1-базы — 500 MB; весь текущий каталог нельзя загрузить в неё без измерения и подготовки.

Цель старта до пяти секунд проверяется по первым декодированным кадрам. Выдача всех источников за пять секунд не гарантируется: внешние сайты имеют собственные задержки. Встроенный движок постепенно добавляет варианты и использует короткий кэш повторного открытия.

## Объём переноса и оставшаяся проверка

В Python-реестре Zona описаны 52 исходных извлекателя; реализованы 18. Остальные возвращают явный статус отсутствующего контракта, сессии или авторизации. Это не означает работу всех 52 источников. Некоторые адаптеры используют внешние API и конфигурацию провайдеров: их доступность зависит от этих сервисов. При отключении такого сервиса сохраняются каталог Movia и остальные источники, но конкретный адаптер нужно заменить прямым разрешённым контрактом.

Нативный движок LazyMedia включён в APK Movia и изолирован от старого приложения: 12 активных провайдеров из исходного реестра 34. Наличие адаптера не доказывает воспроизведение. Проверки реальных исходных CDN обнаружили HTTP 403; резервное воспроизведение через другие источники учитывается отдельно. Работа сервера с PostgreSQL, рестартом, полной базой и реальными провайдерами на IP хостинга остаётся обязательным этапом до отказа от локального API.
