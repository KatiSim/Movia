# Movia — блок 3: стабильная идентичность источников

Дата: 2026-10-07. Блок начат около 13:00 UTC. Устройство: Jarvis 3, основной телефон Екатерины. Работа нативно в Movia; без переноса кода LazyMedia и без фиксированного количества озвучек или качеств.

## Выполнено

- ProviderContract выдаёт полностью scoped provider-item:v2 и logical-source:v2, а публичный stream_id использует ту же устойчивую идентичность. Ключ конкретного provider leaf не зависит от измеренного качества, отображаемого названия озвучки или порядка discovery.
- Идентичность различает каталог, год, media type, трейлер, S/E, транспорт, audio/video track и torrent file. Неоднозначное кодирование частей ключа заменено JSON-массивом.
- HDRezka сохраняет собственный selector переводчика и rendition до измерения качества. Обновление URL применяется только по подтверждённому правилу этого транспорта; неизвестные locator остаются консервативными.
- Torrent BTIH нормализуется из Base32/hex. Дубли одной физической раздачи, найденные разными провайдерами вместе, получают детерминированного владельца вместо first-arrival. Разные раздачи и file selectors не объединяются.
- Zona использует стабильную catalog article identity и ключ каждого leaf вместо ordinal. Удалён локальный лимит 512 строк, проверена обратная перестановка 600 leaves. Provider остаётся выключенным: live parity не доказана.
- Android распознаёт полностью scoped v2 identity: signed URL и уточнённое измеренное качество могут изменяться при reload того же leaf. Каталог и track/file/episode selectors продолжают проверяться. Legacy identity сохраняет прежние строгие ограничения.
