# Movia — часовой блок 6 октября 2026

Начало: около 20:20 UTC. Максимальный срок: 21:19 UTC.

Реализация Movia сохраняет все реальные варианты источников; фиксированного ограничения 3 озвучки × 3 качества нет. LazyMedia используется как поведенческий ориентир, код и runtime этого приложения не добавлены.

В этом блоке:
- Убрана подстановка запрошенной серии в источники без подтверждённых координат. Отбрасываются общие сезонные пакеты, несовпадающие и некорректные S/E.
- HDRezka проверяет активную серию и ID статьи, при необходимости открывает публичную страницу точного эпизода. Озвучка встроенного сериального плеера определяется из TVShows.
- Измерение содержимого распознаёт MP4 даже за URL с расширением m3u8. Полные HLS разных качеств дают подтверждение длительности конкретного эпизода; минутные заглушки отбрасываются.
- Старые записи HDRezka без подтверждённого эпизода и его длительности не проходят серверный и Android read path.
- Media3 проверяет фактическую длительность по данным конкретного эпизода. Не используется длительность всего сериала.
- Ограничены рабочие потоки и очередь измерения содержимого, без обрезания списка настоящих вариантов.
- Исправлен Android crash при постановке загрузки из состояния IDLE с пустым mediaId.

Проверки:
- 387 backend-тестов успешно.
- Живой собственный HDRezka adapter: S01E01 3 486 548 ms, S01E02 2 892 955 ms, S01E03 2 891 954 ms; по 8 подтверждённых листьев, качества 240/360/480/720p. Два минутных источника каждого эпизода исключены.
- На исходной установленной сборке 332: Интерстеллар полностью воспроизводился, English ↔ Russian и 720p ↔ 360p переключались с сохранением позиции; точные ID Spider-Man 2002/1977 не смешивались, но успешное воспроизведение этих двух фильмов не подтверждено.
- Финальные проверки установленной сборки 333 и checkpoint дописаны ниже.

Остаётся:
- Завершить нативную замену низкоуровневых совместимых transport wrappers.
- Расширить реальные голоса и providers только после live playback evidence; не включать недоступные adapters.
- Доказать соответствие torrent audio metadata фактическим Media3 audio tracks.
- Продолжить широкие независимые coverage-аудиты и проверки сериалов/скачиваний. Новая 1000-фильмовая cohort в этом часовом блоке не запускалась.
