# Movia — результат блока 2 октября 2026

Подготовлена Android-сборка **327** и проверена активная серверная часть с **199** проверками. На телефоне установлена **323**. Новые изменения Android ещё не проверены в установленном приложении: предыдущая попытка обновления была отклонена Android с `INSTALL_FAILED_USER_RESTRICTED`. После отказа установка не повторялась.

## Общие исправления

- Запуск из карточки передаёт полные варианты потоков: озвучку, индексы дорожек, заголовки и User-Agent. Список URL больше не теряет эти данные.
- Выбранный стартовый вариант больше не скрывает остальные проверенные варианты из кэша до завершения поиска провайдеров.
- Карточка и потоки связаны с точным ID фильма или точной парой сезон/серия. Потоки серии без названия релиза больше не попадают в карточку фильма.
- Короткое API карточки не запускает миграции, обогащение или диагностические записи. Диагностика источника читает SQLite без записи для сверки срока действия.
- Прямое чтение карточки воспроизведения работает до появления русского названия. Оно не подменяет отсутствующий внутренний ID результатом поиска по TMDB или названию.
- Рабочие ссылки Internet Archive принимаются. Адреса метаданных TMDB отбрасываются по точному имени хоста.
- Явно выбранные источник, озвучка и качество загрузки не заменяются другим вариантом. Выбранный HLS/DASH скачивается через его исходный поток и профиль заголовков; отдельная MP4-ссылка не подменяет выбранную дорожку или разрешение.
- Индексы озвучек сохраняют порядок провайдера, включая неподдерживаемые дорожки. Кодековые копии одной озвучки не становятся новыми озвучками. Неподдерживаемые варианты убираются из меню после подготовки потока.
- При смене дорожек сохраняются пауза и позиция. Техническая идентичность дорожки не зависит от изменяющейся подписи в меню.

Это изменения общих механизмов. Исключений в коде для отдельных названий фильмов не добавлялось.

Всего в основной выборке было 540 ID. Проверены отсутствие пересечений с 961 ранее проверенным ID и уникальность идентичностей по TMDB либо исходному названию/году. «Интерстеллар», использованный в предыдущей работе, дополнительно исключён из счёта новых фильмов.

Первый прогон дал 486 успешных стартов. Повторная проверка 16 видео без звука дала 14 подтверждённых декодирований без обнаруженной аудиодорожки. Эти видео не считаются примерами нескольких озвучек. Повторный прогон остальных 38 отказов дал 5 успешных декодирований. Повторные успехи объединены по идентичности фильма; отдельные попытки и первоначальные отказы сохранены.

Проверка связывает источник с карточкой и проверяет реальные декодированные кадры, PCM при наличии звука, выбранные форматы и новые кадры после переключения. Названия студий не подтверждены независимым прослушиванием. Само содержание всех фильмов не идентифицировано по кадрам. Все провайдеры и все альтернативные профили всех 504 фильмов не проверены.

Отдельный повторный замер после исправления чтения карточек: 3,782 с; 5,180 с; 2,265 с от команды до стабильных кадров. Это повторные старты в уже работающем приложении. Последняя проверка короткого API карточки дала 47–357 мс; её время не считается временем запуска видео.

## Где парсер

Рабочий парсер всё ещё работает в Termux: `projects/media-parser`, служба `movia-media-parser`. Собственный переносимый серверный код опубликован в `backend/runtime` этого репозитория. Вне телефона сервер не развёрнут; доступа к хостингу в этой сессии нет.

Тяжёлые службы `movia-stream-enricher` и `movia-metadata-enricher` остановлены. В финальной проверке процессов тяжёлых обогатителей не обнаружено. Для поиска по запросу применяются ограниченные очереди и до двух работников. Каталог содержит 96 802 карточки, SQLite quick_check: ok. Экономия батареи и RAM в процентах не измерялась.

Полная независимость от старых внешних API не достигнута. Перенос всего реестра LazyMedia/Zona и проверка источников с IP внешнего сервера остаются отдельной незавершённой работой.
