# Movia — продолжение проверки 3 октября 2026

## Что активировано

- `stream_validation.py`: track index теперь принимает только неотрицательный Android Int. Отрицательные sentinel-значения, bool, дробные, нечисловые и переполненные значения не превращаются в реальную дорожку 0. Реальный индекс 0 сохраняется.
- `stream_identity.py`: отсутствие ещё не обогащённого названия больше не отключает независимые проверки catalog ID, года, типа контента и точной пары сезон/серия.
